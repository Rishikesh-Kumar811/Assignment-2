## ✨ Key Features

<br/>

### 1. 🖼️ Multi-Aspect Responsive Gallery Architecture
- **Dynamic Layout Distribution**: Intelligently organized multi-column photo grid adapting gracefully to screen dimensions.
- **Aspect-Ratio Stability**: Explicit aspect ratio preservation preventing layout shifts (0.0 CLS) during media loading.
- **Hero Image Integration**: Dominant `main.avif` visual anchor setting the tone for the editorial showcase.

### 2. ✨ Fluid Micro-Interactions & Hover State Overlays
- **Smooth Image Transformations**: Hardware-accelerated CSS `transform: scale()` transitions on user hover.
- **Luminous Card Boundaries**: Subtle border and shadow adjustments enhancing spatial depth.
- **Zero-Lag Interaction**: GPU-composited transitions delivering a fluid 120FPS visual experience.

### 3. 📐 Strict Box-Model Discipline & Container Proportioning
- **Predictable Layout Engine**: Systematic application of `box-sizing: border-box`, clean padding scales, and margin resets.
- **Fluid Container Bounds**: Maximum width clamping preventing horizontal stretching on ultra-wide desktop monitors.

### 4. 📱 Flawless Responsive Breakpoints
- **Mobile-First Scaling**: Seamless single-column flow on smartphones expanding to multi-column desktop arrangements.
- **Touch-Friendly Controls**: Generous interactive padding ensuring comfortable tap targets on touch devices.

## 🚀 Quick Start & Local Setup

### 1. Clone the repository
```bash
git clone https://github.com/Rishikesh-Kumar811/Assignment-2.git
cd Assignment-2
```

### 2. Launch with Live Server
Open `index.html` in your web browser, or launch using a local HTTP server:

```bash
npx serve .
```

Visit `http://localhost:3000` in your web browser.
